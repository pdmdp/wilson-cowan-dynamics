# Neuromatch course material

The foundational Wilson–Cowan equations, parameter choices and tutorial helpers in the coursework notebook follow Neuromatch Academy's [Wilson–Cowan tutorial](https://compneuro.neuromatch.io/tutorials/W2D5_DynamicalSystems/student/W2D5_Tutorial2.html) and its [extension tutorial](https://compneuro.neuromatch.io/tutorials/W2D5_DynamicalSystems/student/W2D5_Tutorial3.html). The course material is available under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), with software additionally licensed under BSD 3-Clause. The notebook extends that base with parameter scans, stochastic simulations and input-pulse experiments.

The November 2026 module restates the same base model using SciPy's stable sigmoid, validates root solutions and uses one response function across its simulation modes. It includes a separate, documented numerical review.
